# موقع متجر الوجدي

هذا موقع متجر إلكتروني/كتالوج جاهز كبداية، بهوية متجر الوجدي:
- العربية RTL
- ألوان أخضر داكن + ذهبي
- الأقسام: تنظيف، منزل ومطبخ، غذائية، سفر
- سلة مشتريات
- طلب مباشر عبر WhatsApp
- خدمة DAMANE PAY
- توقيت: الاثنين إلى الأحد، 10:00–14:00 و17:00–22:00
- الهاتف/واتساب: 0721851643
- العنوان: حي النرجس، فاس، بالقرب من Golden Gym

## تعديل المنتجات
افتح `products.js` وغير الأسماء والأثمان والأقسام.

## تشغيل الموقع
افتح `index.html` في المتصفح.

## نشر الموقع
يمكن رفع مجلد الموقع كما هو إلى أي استضافة مواقع ثابتة. بعد ذلك يمكن ربط دومين مثل:
`www.alwajdi.ma` أو أي دومين متوفر.

## ملاحظة مهمة
هذه النسخة لا تحتوي على قاعدة بيانات أو لوحة تحكم حقيقية. الطلبات تتم عبر WhatsApp. إذا أردت الدفع الإلكتروني، إدارة المخزون، تسجيل الزبائن، ولوحة تحكم لإضافة المنتجات، نحتاج إضافة Backend وقاعدة بيانات في المرحلة الثانية.
